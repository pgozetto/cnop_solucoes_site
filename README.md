# CNOP Soluções

Site institucional da CNOP Soluções, empresa especializada em consultoria empresarial, Segurança do Trabalho, Gestão de Pessoas e organização de processos.

## Sobre o projeto

O site apresenta a atuação da CNOP, os principais serviços oferecidos e os canais de contato da empresa. A experiência foi construída com foco em clareza, credibilidade e navegação responsiva para empresas e profissionais.

## Principais recursos

- Hero institucional com efeitos de entrada, typewriting e parallax.
- Apresentação da Camila Perboni e da CNOP Soluções.
- Soluções organizadas por áreas de atuação:
  - Segurança do Trabalho e SST;
  - Gestão de Pessoas e RH;
  - Departamento Pessoal e Processos;
  - Soluções Digitais.
- Detalhamento das soluções em acordeão, com transições de abertura e fechamento.
- Botões de contato direto pelo WhatsApp e Instagram.
- Layout adaptado para desktop, tablet e celular.
- Favicon e identidade visual alinhados à marca CNOP.

## Tecnologias

- Next.js/Vinext
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Executar localmente

Requisitos: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:5173` (ou a porta indicada pelo terminal).

## Build de produção

```bash
npm run build
npm run start
```
